# CODING_STANDARDS.md — 代码与测试规范细则

> 细则文件。由 AGENTS.md 任务路由表加载（代码修改/测试类任务）。
> 标记规则：【强制】违反即违纪；【应当】偏离需说明；【可选】无后果。
> 本项目技术栈：Python 3.12 + PySide6（桌面 GUI 悬浮窗；数据源为只读的外部 SQLite）。

## 注释与文档

- 【强制】每个源码文件首行必须有模块级说明（docstring 或文件头注释），一句话说明职责。
- 【应当】注释写"为什么做"，非直观逻辑必须注释。
- 【强制】修改逻辑时同步更新模块说明和行内注释。

## PySide6 桌面 GUI 规范

### 外部数据源只读纪律

- 【强制】ZCode 数据库（`~/.zcode/cli/db/db.sqlite`）必须以只读模式打开（`sqlite3` URI 加 `?mode=ro`）；禁止任何写操作、建表、`VACUUM`、写型 `PRAGMA`。
- 【强制】程序不持有写连接；连接只读打开、长期复用或即用即关，不得以任何方式升级为读写。
- 【强制】读库失败（文件锁、schema 变化、路径不存在）时降级显示（保留上次值并标注状态）或给出明确错误提示，不得崩溃退出、不得重试写入。

### 线程与响应

- 【强制】UI 线程纪律：SQLite 轮询、聚合计算不得阻塞主线程；用 `QTimer` 异步轮询或 `QThread`，不在主线程 `sleep` 或跑长循环。
- 【强制】数据与界面分离：读库与统计聚合（按天/分模型/单位换算）独立于窗口组件模块，UI 只消费数据对象。
- 【强制】聚合与换算函数纯函数化（输入原始行、输出统计值），便于单元测试锁住口径。
- 【应当】轮询间隔作为常量集中定义；读取异常时退避重试，不忙等空转。

### 视觉与设计常量

- 【强制】颜色、字号、间距、圆角、动画时长等设计常量集中定义在主题模块（落地建 `theme.py`），组件代码内不得散落内联色值（十六进制）。
- 【强制】窗口为无边框置顶形态；窗口位置/尺寸持久化到本地配置文件，恢复时校验是否落在当前屏幕范围内，防止窗口跑到屏幕外。
- 【应当】动画统一走 `QPropertyAnimation`/`QTimer` 帧驱动；时长档位取自主题模块。
- 【应当】信号槽用新式语法（`signal.connect(slot)`），不用字符串式写法的旧接口。
- 【应当】退出时显式清理系统托盘图标（`QSystemTrayIcon`），防止幽灵图标残留。
- 【强制】视觉还原以实际截图对照设计稿验收；未对照截图声称"还原完成"不算完成。

## 测试规范

> 测试运行纪律是跨技术栈通用的，直接适用；数据源纪律见下方「测试数据源纪律」。

- 【强制】任何情况下都不得自主运行全量回归（`python -m pytest -q`），是否全量回归由用户决定。
- 【应当】日常小范围修改优先运行直接相关测试，并在汇报中说明跑了哪些、为什么跑这些。
- 【强制】新增或修改会随记录数增长的列表、详情聚合、统计、导出代码时，必须新增或更新查询形态回归测试：分别构造小数据量和大数据量，断言查询次数不随记录数线性增长；不得只用单条数据证明"功能可用"。
- 【应当】单个业务服务及其对应路由的小范围修复，优先运行直接相关测试；当相关测试无法覆盖影响面、或发现异常需要扩大排查时，不要自行升级到全量回归，而是在汇报中提出"建议进行全量回归"并说明理由。
- 【应当】本次改动触及模型关系、权限体系、数据库迁移、审核流程、配置、跨模块共享接口、公共基础服务，或临近上线/合并时，不要自行运行全量回归，而是在任务结束的汇报中提出"建议进行全量回归"并说明理由，由用户决定是否执行。
- 【强制】用户明确要求执行测试时，按用户要求执行（含全量回归）。
- 【应当】关键界面路径配 GUI 自动化验证（截图对照脚本或人工对照设计稿）；耗时验证默认跳过、显式开启后运行是常见做法，是否采用按项目测试策略。
- 【强制】GUI 自动化验证在本地环境运行；验证过程只读 ZCode 数据库，不得访问或写入任何真实数据。
- 【应当】测试命名遵循项目约定（如 `test_模块_场景` 或 describe/it 描述性语句）。
- 【应当】断言统一使用框架标准断言。

### 测试数据源纪律（无自有数据库）

- 【强制】测试一律不得读写 ZCode 真实数据库（`~/.zcode/cli/db/db.sqlite`）及 `~/.zcode/` 下任何文件。
- 【强制】需要 SQLite 语境的测试用 `:memory:` 或 `tmp_path` 临时文件库；夹具自建数据、用完即删，并断言连接的不是真实库路径。
- 【强制】聚合统计（按天/分模型/单位换算/增量计算）必须有单元测试锁住预期行为。
