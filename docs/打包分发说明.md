# 打包分发说明

> 本文面向两类读者：拿到 exe 的使用者（前半），维护本仓库的构建者（后半）。

## 使用（拿到 ZCodeTokensCard.exe 后）

1. **运行**：双击 `ZCodeTokensCard.exe`，桌面右下角出现用量悬浮卡，系统托盘出现绿色 Z 图标。无需安装，重复双击只会唤醒已有窗口（单实例）。
2. **托盘菜单**（右键托盘图标）：
   - 仅 ZCode 聚焦时显示（默认开）：ZCode 或卡片在前台时显示，否则隐藏；
   - **开机自启动**：勾选后写入当前用户注册表 Run 键（`HKCU\...\CurrentVersion\Run`，条目名 `ZCodeTokensCard`），取消勾选即删除，无需管理员权限、立即生效；exe 换了存放位置也不用管，程序下次启动会自动把自启动路径修正到新位置；
   - 显示 / 隐藏；退出（退出即清理托盘图标）。
3. **移动卡片**：左键拖动，位置自动记住。
4. **数据来源**：卡片只读读取本机 ZCode 桌面端的数据（`~/.zcode/cli/db/db.sqlite` 与 `%APPDATA%\ZCode\session\Local Storage\leveldb`），对 ZCode 数据零写入。**本机需装有 ZCode 桌面端**；没有 ZCode 或读不到数据时，卡片进入"数据源异常"状态（呼吸灯变红橙），程序不崩溃。
5. **状态文件**：打包版把窗口位置等状态存在 `%APPDATA%\ZCodeTokensCard\state.json`。

### 已知限制

- 依赖 ZCode 的内部数据结构（表、localStorage 键名）；ZCode 大版本更新可能使部分显示退化（如"当前对话"行失去切换跟随），不会产生错误数据。
- PyInstaller 打包的程序偶被杀毒软件误报，加入白名单即可。

## 构建（维护者）

环境：本机 Python312（`%LOCALAPPDATA%\Programs\Python\Python312`，须带 PySide6）。

```bash
# 1. 依赖(一次性)
python -m pip install pyinstaller

# 2. 生成/更新图标(托盘图标样式变化时重跑)
python tools/make_icon.py

# 3. 打包
python -m PyInstaller ZCodeTokensCard.spec --noconfirm --distpath dist --workpath build
```

产物：`dist/ZCodeTokensCard.exe`（单文件、无控制台）。`build/`、`dist/` 不入库。

打包相关行为要点（详见 `.rules/FEATURE_MAP.md`）：

- 冻结模式下 `config.config_path()` 走 `%APPDATA%\ZCodeTokensCard\state.json`（onefile 的程序目录是临时解压目录，写仓库内会丢）；源码模式行为不变。
- 自启动命令在冻结模式下就是 exe 自身路径；源码模式为 `pythonw.exe main.py`。
- 自启动路径漂移（exe/仓库挪位）由启动时的 `autostart.sync()` 自愈：条目存在但指向旧位置时覆盖为新命令，未开启则不动。
